**SLM Cost Calculator — README**

Продвинутый инженерный калькулятор для оценки полной себестоимости и рекомендуемой цены производства изделий методом Selective Laser Melting (SLM).
Подходит для технологов, инженеров, проектных менеджеров и производственных центров.

**🚀 Назначение проекта**

Инструмент позволяет:
- загружать STL-модели и автоматически получать объём детали и поддержек;
- учитывать параметры конкретной SLM-установки;
- рассчитывать себестоимость запуска (материал + машина + ФОТ + постобработка);
- получать вилку рекомендуемой цены для коммерческого предложения;
- стандартизировать процесс оценки для менеджеров и инженеров.

**📄 Выходные данные**

Калькулятор формирует:
- полную себестоимость запуска
- себестоимость одной детали
- рекомендованный диапазон продажи
- подробный отчёт по структуре затрат

**📌 Статус проекта**

MVP в разработке.
Следующие шаги: автоматический парсинг STL, сохранение пресетов принтеров, экспорт расчётов.
Репозиторий в активной разработке. Структура и API могут меняться.
